# Type Definitions

This directory will contain shared TypeScript type definitions.

## Current Types

All types are currently defined in `lib/api.ts` and exported for use throughout the application.

## Planned Structure

| File | Description |
|:---|:---|
| `api.ts` | API response/request types (already in `lib/api.ts`) |
| `domain.ts` | Domain model types (Parcel, Owner, Transaction, Case) |
| `ui.ts` | UI-specific types (RiskLevel, StatusPill variants, etc.) |
