# UI Components

This directory will contain reusable React components extracted from the main `App.tsx`.

## Planned Components

| Component | Description |
|:---|:---|
| `RiskBadge.tsx` | Color-coded risk level indicator |
| `StatusPill.tsx` | Transaction/case status pill |
| `DataTable.tsx` | Generic sortable/filterable table |
| `MetricCard.tsx` | Dashboard metric card |
| `Modal.tsx` | Reusable modal wrapper |
| `Sidebar.tsx` | Navigation sidebar |
| `TopBar.tsx` | Top navigation bar |

> **Note**: The current application has all components defined in `App.tsx`. These will be extracted into separate files as the project evolves.
