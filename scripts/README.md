# Utility Scripts

This directory contains helper scripts for development and deployment.

## Planned Scripts

| Script | Purpose |
|:---|:---|
| `setup.sh` | One-command project setup (venv, dependencies, DB init) |
| `run_backend.sh` | Start the FastAPI backend server |
| `run_frontend.sh` | Start the Vite frontend dev server |
| `retrain_model.sh` | Regenerate synthetic data and retrain the ML model |

All scripts are designed for Windows (PowerShell) environments.
